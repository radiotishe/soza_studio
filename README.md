# Радио СОЗА — студия контента

Веб-приложение из одного файла (`index.html`) для подготовки и планирования постов.
Открывается прямо в браузере, всё сохраняется на устройстве. Сборка не нужна.

## Разделы (меню — кнопка ☰ снизу справа под карточками, или слева на компьютере)
1. **Редактор** — карусель: обложка (текст/фото), текстовые слайды, финал.
   - Тап по обложке: режим текст ⇄ фото. В фото — перетаскивание текста, линии центровки, затемнение (верх/центр/низ).
   - Текстовые слайды: тап по слову → 🗑 / Ж / К сверху; двойной тап → правка; Enter переносит остаток текста в новую карточку.
   - Шрифты: SF, Golos, Inter, Manrope, Onest, Brockmann, Georgia. Минимальный размер текста — 21px.
   - Отмена действия — кнопка ↶.
2. **Библиотека** — тексты из Instagram (17) и Telegram (84):
   - готовые карусели, статусы IG / TG / VK; «Архив» (выложенное); «Готовые» (сохранённые карусели), «Сетка 3×3» (превью ленты Instagram);
   - «В редактор» — загрузить текст (умная нарезка по предложениям).
3. **Контент-план** — календарь по месяцам; «+» в дне прикрепляет готовую карточку и площадку (IG/TG/VK).

## Как выложить на GitHub + Vercel (без терминала)

1. **GitHub** → войти → **New repository** → имя `kartochki`, тип **Public** → **Create repository**.
2. На странице репозитория → ссылка **uploading an existing file** → перетащить **index.html** (и при желании README.md, vercel.json) → **Commit changes**.
3. **Vercel** → войти **Continue with GitHub** → **Add New… → Project** → найти `kartochki` → **Import** → **Deploy**.
4. Через ~20 секунд появится ссылка вида `kartochki.vercel.app` — это рабочее приложение.

Любая правка `index.html` на GitHub автоматически обновит сайт на Vercel.

### Через терминал (Mac)
```
mkdir kartochki && cd kartochki
# положить сюда index.html (и README.md, vercel.json)
git init
git add .
git commit -m "Студия контента: первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/kartochki.git
git push -u origin main
```
Затем импортировать репозиторий в Vercel (шаги 3–4).

## Важно
- Файл должен называться **index.html** и лежать в корне репозитория.
- Данные хранятся в браузере на устройстве (у каждого свои). Это не общая база.
